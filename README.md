# To-Do List - Vanilla JavaScript

Piccola applicazione per gestire una lista di attività, realizzata con HTML, CSS, JavaScript e Vite.

## Funzioni

- Aggiungere una nuova attività.
- Segnare un'attività come completata cliccandoci sopra.
- Eliminare un'attività con il pulsante `×`.
- Visualizzare il numero totale di attività e quelle completate.
- Salvare le attività nel `localStorage`, così restano disponibili anche dopo aver chiuso o aggiornato la pagina.

## Come avviare il progetto

È necessario avere Node.js installato.

Aprire il terminale nella cartella del progetto ed eseguire:

```bash
npm install
npm run dev
```

Aprire nel browser l'indirizzo mostrato dal terminale.
